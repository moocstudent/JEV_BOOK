## Repoint the baseUrl and you are done

After `pip install "laya[serve]"`, `laya-serve` exposes exactly Jev's `POST /v1/systemone` with an aligned response schema, so an existing Jev client needs only its `baseUrl` repointed and nothing else — the most practical value an open alternative offers, more direct than any benchmark score.

## Configuration item by item

- `LAYA_DEVICE`: `cuda` or `cpu`.
- `LAYA_PRELOAD`: whether checkpoints load at process start or on the first request. The latter means your first user pays the load — measured here at 18.5 seconds cold for the English checkpoint.
- `LAYA_MODELS`: the comma-separated preload list; two checkpoints, english and multilingual, are kept hot by default under LRU.
- `LAYA_THREADS`: cap at the physical core count for CPU inference, because more is slower.
- `LAYA_API_KEY`: once set, clients must send `Authorization: Bearer`.

## One layer you must add yourself

There is no authentication by default, and this service takes arbitrary text and returns judgements — it does not belong on the public internet. Set `LAYA_API_KEY` and keep it behind an internal network or gateway. If you serve one language, preloading only that checkpoint saves a few hundred megabytes.
